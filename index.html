The Core Inversion

Why the industry's 3D mesh-diffusion obsession is an un-riggable dead end.

Diffusion 3D (Mesh Soup) Broken

Generating 3D by diffusing polygon vertices produces millions of disordered triangles with chaotic topology. It cannot be animated, cannot be rigged, cannot be diffed in git, and costs dollars per iteration.

# Output from 3D diffusion: unrigged_blob.obj (142MB) - 1,840,000 non-manifold triangles - Zero semantic collections or hierarchy - Un-diffable binary mesh in git

RealEngine (Code-to-3D) Deterministic

Compiles natural language into an authoritative, machine-checked contract (SCENE_SPEC.md), then renders clean parametric geometry, procedural shaders, and named cameras on both Blender and Web.

# Output from RealEngine: SCENE_SPEC.md (8KB, git-diffable contract) ├──► out.blend (Blender modifiers, collections, cameras) └──► scene.html (Standalone Three.js WebGL, 60fps)

Tiny Surface, Deterministic Execution

Exactly 6 MCP verbs, all wired to real steps. Agents never see raw bpy or low-level GL. A verb whose dependency is missing says so and returns ok:false — it never fakes a result.

The 6 MCP Verbs

  • brief Draft SCENE_SPEC.md from words, schema-checked. needs a model endpoint
  • spec_compile Spec → pinned build JSON. Offline, deterministic. live
  • build Standalone Three.js page, or .blend via headless Blender. live
  • views PNGs of every named camera, or a manifest any browser can drive. needs headless Chromium
  • qa_assert Zero-vision OCR label gate over a renders directory. needs renders + zero-vision
  • export_scene Deterministic zip with a sha256 manifest, or one HTML/PNG. live

Zero-Vision QA Gate

Machines check, humans judge taste. Before any render is shown to a human reviewer, RealEngine's QA runner uses Zero-Vision OCR to assert label legibility, camera bounds, and object overlap in milliseconds.

$ python3 qa/run_qa.py --renders examples/brain --labels "Thalamus,Hippocampus" QA gate: 7 PNG(s) in examples/brain PASS 01_master_front.png PASS 02_left_orthographic.png PASS 03_top_orthographic.png RESULT: PASS

Run test suite $ python3 -m unittest discover -s tests -p 'test_*.py'
